# Kerem'le Travel UGC

Kerem Kargın'ın Travel UGC, otel iş birlikleri, dijital kaynaklar ve birebir danışmanlık sitesi.

## Fotoğrafları değiştirme

Gerekli dosya adları ve önerilen ölçüler için [`FOTOGRAF-REHBERI.md`](FOTOGRAF-REHBERI.md) dosyasını kullanın. Fotoğraflar `assets/images/` klasörüne aynı dosya adlarıyla yüklenmelidir.
